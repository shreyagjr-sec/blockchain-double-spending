# Project background

This project is based on the blockchain work in **Preventing Double Spending Attacks in Cryptocurrency Blockchains Using Network Observer and Peer-Alert System**, submitted by **Shreya Gajjar** in April 2024.

It was part of the Computer Engineering internship at GTU Graduate School of Engineering and Technology. The original source was supplied in `Blockchain.zip`.

The repository now contains the updated Ledger Lab code, run results, screenshots, and only the blockchain chapter of the report. The original full report has not been changed.

The later code fixes and dashboard were developed with AI assistance. The original report and the updated implementation are kept separate so the changes are clear.
