# Project Description

An educational JavaScript blockchain prototype exploring double-spending detection through pending-transaction monitoring and peer alerts. The project report demonstrates hash validation, signed transactions, conflicting payments, observer warnings, and a model-specific response workflow.

**Author:** Shreya Gajjar

**Context:** Computer Engineering internship project, GTU Graduate School of Engineering and Technology, January–April 2024.

**Tools described:** JavaScript, Node.js, and the `elliptic` library.

**Repository status:** Documentation and report figures published; source code pending upload.
